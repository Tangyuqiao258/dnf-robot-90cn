# 90CN 能力状态

本文档记录当前仓库对应的 DNF90（90CN）模拟端能力边界。状态只描述本仓库已经实现的代码和已完成的验证，不代表服务端本身具备同名功能。协议实现依据 90CN 服务端源码（**服务端仓库**，本机检出 `G:\90-CN\server-90\go-server`；`internal/services/`、`internal/modules/dnf/` 下的路径均指该服务端仓库，不在本仓库）；本仓库对应实现见 `internal/protocol/cn90` 与 `internal/composition/backend/cn90`。服务端契约摘要见 [`90CN适配笔记.md`](90CN适配笔记.md)。
