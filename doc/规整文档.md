# 规整文档

本仓库全库禁止 `README.md`（架构测试 `TestReadmeFilesDoNotFragmentDocumentation` 执法，根目录同样适用），全部文档集中在 `doc/`。本文档是阅读入口与文档索引。

## 这是什么

90CN（DNF 单机服务端）的**假人机器人**：一个直接讲服务端线路协议的进程内客户端，把建号、上线、配装、走位、喊话、摆摊/拍卖/邮件等行为批量自动化，用来把城镇点活。它不是外挂、不改客户端——机器人自己实现 90CN 的登录与游戏协议（`internal/protocol/cn90`），以真实角色身份登录，服务端把它当普通玩家对待。分层与装配见[架构设计](架构设计.md)，目录职责见[代码图谱](代码图谱.md)，跑起来的前提见[构建与发布](构建与发布.md)的安全部署一节（Windows 入口检查、8111 不鉴权、8112 默认口令 `twadmin`）。
