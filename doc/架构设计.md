# Robot 架构设计

## 分层

```text
公共内核
  生命周期、Actor、调度、统一状态、统一锁、Web/API、配置

能力编排
  基础能力、交际能力、交易能力、失败重试和结束恢复

适配层
  版本描述、协议、PVF 转换、角色发现、持久化边界、版本能力
```

公共层表达业务意图，适配层负责具体协议和存储实现。公共层不得依赖具体版本、协议 opcode、数据库驱动、表名或服务脚本。

## 生命周期

```text
初始化 → 调度 → 结束
```

初始化读取配置、释放适配端文件、加载 PVF 和模板、发现角色并建立内存快照。调度执行登录、保活、移动、喊话、组队、公会和交易等已声明能力。结束停止新任务，清理交际/交易状态，退出角色，保存必要数据并关闭资源。

## 能力分组

- 基础：登录、退出、保活、城镇移动、普通喊话和在线人数调度。
- 交际：组队接受、城镇跟随、公会邀请和队伍结束恢复。
- 交易：摆摊、副职业、分解、拍卖、金币寄售和交易数据。

适配器声明能力和模式；不支持的能力返回统一 unsupported，由 Web 隐藏或置灰。

## 业务逻辑

名字模板、等级范围、装备/装扮成套与多样性、宠物、角色缺口、重试退避、组队解散恢复等成熟逻辑保留在公共编排层。适配器只负责应用统一业务方案。

## 新增适配端

复制仓库后替换适配层，补充版本描述、协议、PVF 投影、角色发现和持久化实现。不得在调度器、Actor 或 Web 中增加版本名称判断。
